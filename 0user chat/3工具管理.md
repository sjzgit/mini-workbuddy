# 工具管理

工具决定了 Agent 能执行哪些操作。第一版先提供三类内置工具，满足基本的查询和执行需求：
- 时间工具：根据用户指定的时区，返回当前时间。
- Shell 工具：执行命令，并返回执行结果。
- 文件读写工具：读取文件内容，以及创建和修改文件。
工具页面需要展示工具名称、用途说明、参数说明、启用状态，以及是否为系统内置工具。用户可以启用或停用工具，也可以进入详情页查看参数的含义。系统内置工具允许启停，但不允许删除或修改其用途。
工具说明需要明确适用场景、输入要求和使用限制，帮助模型判断何时调用、如何填写参数。
- 当前时间工具：用于查询指定时区的当前日期和时间。时区参数使用 IANA 时区名称，例如 Asia/Shanghai（北京时间）、America/New_York（纽约时间）或 Etc/UTC（协调世界时），避免使用 CST 等含义不明确的缩写。用户未指定时区时，使用系统配置的默认时区。
- Shell 工具：用于执行命令，例如查看系统信息、搜索文件、运行脚本和执行测试，并返回命令输出及执行状态。禁止执行可能造成严重破坏或泄露敏感信息的命令，包括递归删除根目录或系统目录、格式化磁盘、修改关键系统权限、关闭安全防护、读取并外传密钥，以及未经检查直接执行远程下载的脚本。
- 文件读写工具：用于读取、创建和修改授权目录内的文件。参数说明需要明确文件路径的填写方式、读写内容的格式，以及文件不存在或已存在时的处理规则。
危险操作的限制需要在工具执行层落实，不能只依靠工具说明约束模型。

请建立统一的工具执行入口。后续 Agent Loop 调用任何本地工具都要经过这里。执行前检查工具是否存在、是否启用、输入是否正确。执行后返回统一且容易理解的结果。执行失败时保留清楚的错误信息，不能让整个后端进程崩溃。
