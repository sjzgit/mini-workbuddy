# 初始化系统

## 固定技术栈

前端使用下面这组技术:
- Vue 3、TypeScript、Vite、Vue Router、Pinia、sass、npm 管理依赖、Ant Design
- 前端测试使用 Vitest。不要使用 React、Next.js、Nuxt、Django、Flask
- 前端在开发环境中始终请求相对路径 /api，由 Vite 转发到后端。

后端使用下面这组技术:
- Python 3.12、FastAPI、Pydantic、SQLAlchemy、Alembic、SQLite
- uv 管理 Python 和依赖
- pytest 编写后端测试
- 在 backend 目录中用 uv 初始化 Python 项目。后端必须生成并维护 pyproject.toml 和 uv.lock。添加依赖使用 uv add，安装依赖使用 uv sync，运行后端命令使用 uv run。Alembic 和 pytest 也通过 uv run 执行。README 中不能出现要求用户直接运行 pip 的步骤。
- SQLite 是本课程唯一的数据库。请在后端准备正式的数据库连接和 Alembic 迁移。后续功能都把数据写入数据库，不使用 JSON 文件代替数据库。

前端代码放在 frontend/src。页面、路由、状态、请求封装、通用组件和样式分开放置。后端代码放在 backend/app。应用入口、路由、业务逻辑、数据访问和数据校验各自放在含义明确的目录下。

请在项目根目录的 AGENTS.md 目前是空的，需要你补充完善。文件中写清项目名称、固定技术栈、前后端目录、常用启动和测试命令、Python 必须使用 uv 的规则、数据库迁移方式、配色与字号入口，以及每次修改后需要运行的前后端检查，必须包含项目前后端开发规范（采用前后端使用技术栈的常见规范要求）。后续开发约定有变化时更新这一个文件，不要让相同规则散落在每份任务说明中。

不要为了显得完整创建大量空文件。当前没有业务内容的模块只保留一个前端占位页面，不提前搭空的后端目录。
应用布局

## 产品基础布局

1. 整个页面占满浏览器高度，不出现整页横向滚动。

2. 桌面宽度下，左侧导航固定为 188px。右侧内容区占据剩余空间。导航顶部显示产品名称 mini-workbuddy，可以配一个简单的圆形字母标记。导航项高度为 32px 左右，图标、文字和选中背景保持对齐。

3. 左侧菜单按下面顺序显示：
   1. 聊天
   2. Agent 管理
   3. 模型管理
   4. 工具管理
   5. MCP 管理
   6. Skills 管理
   7. 运行记录
   8. Agent 评测

4. 默认打开聊天页面。每个菜单都要有独立地址，点击后右侧页面正常切换。刷新任意地址仍能打开对应页面，不能出现空白页。

5. 右侧页面使用统一结构。顶部放页面标题和一句简短说明，下面放内容卡片。占位页面写明“本模块将在后续阶段开发”，并告诉使用者当前阶段先完成什么。不要放虚构的统计数字、对话和列表。

6. 浏览器宽度小于 900px 时，左侧菜单可以收起为窄栏或抽屉。选择其中一种稳定做法即可。收起后仍能打开所有菜单，主内容不能被菜单盖住。

### 固定配色系

请把颜色集中定义为全局 CSS 变量，所有页面和组件都使用这些变量。不要在不同页面随意写相近色。

```css
:root {
  --bg-deep: #f7f3ec;
  --bg-base: #faf7f1;
  --bg-surface: #ffffff;
  --bg-elevated: #ffffff;
  --bg-hover: #f0ebe2;
  --bg-active: #e8e1d6;

  --border: #e4ddd3;
  --border-hover: #d4cbc0;
  --border-strong: #cdc3b6;

  --accent: #c2703a;
  --accent-hover: #a85f30;
  --accent-dim: rgba(194, 112, 58, 0.08);

  --text-primary: #2d2017;
  --text-secondary: #7a6b5d;
  --text-tertiary: #a89882;
  --text-inverse: #ffffff;

  --success: #27896a;
  --warning: #b8860b;
  --danger: #c0392b;
}
```

各色块按照下面方式使用:

- 浏览器最外层背景使用 --bg-deep
- 页面主内容背景使用 --bg-base
- 卡片、弹窗和输入区域使用 --bg-surface
- 鼠标经过的列表项使用 --bg-hover
- 当前选中的菜单项使用 --bg-active
- 主按钮使用 --accent，鼠标经过使用 --accent-hover
- 普通边框使用 --border
- 标题和主要内容使用 --text-primary
- 说明文字使用 --text-secondary
- 时间、占位说明等弱信息使用 --text-tertiary
- 成功、警告和失败状态分别使用对应语义色

页面不能出现蓝紫渐变、霓虹光效、大面积纯黑背景和高饱和荧光色。阴影保持很轻，只用于弹窗和浮层。卡片主要依靠白色背景和浅色边框区分。
字体和字号

### 统一字体

正文优先使用 DM Sans。页面标题和产品名称优先使用 Outfit。代码、命令和日志使用 Fira Code。字体文件不可用时，依次回退到系统无衬线字体和系统等宽字体，不能因为网络字体加载失败让页面无法使用。

请集中定义字体变量。
```css
:root {
  --font-body: 'DM Sans', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif;
  --font-display: 'Outfit', 'DM Sans', -apple-system, BlinkMacSystemFont, sans-serif;
  --font-mono: 'Fira Code', 'SF Mono', Monaco, Menlo, Consolas, monospace;
}
```
字号按照下面规格执行。

- 页面主标题使用 18px，字重 650
- 卡片标题使用 14px 到 15px，字重 600
- 正文和表单使用 12.5px
- 按钮和菜单文字使用 12px 到 12.5px
- 辅助说明和时间使用 10.5px 到 11.5px
- 代码和命令使用 12px
- 正文行高使用 1.5
不要用 32px 以上的大标题。这个项目是紧凑的工作台，不做宣传落地页。
