Agent 评测

请在当前 mini-agent 项目中开发基础 Agent 评测。聊天、Agent Loop、历史会话、上下文管理和运行记录已经可用。
评测必须调用同一个 Agent Runtime，复用模型配置、Skills、工具权限、上下文管理和 Run 记录，不得另外实现一条简化的 Agent 执行路径。评分模型使用统一的模型调用基础设施，但不执行 Agent 工具循环。

数据集管理
评测页面分为“数据集”和“评测任务”两个部分。
用户可以创建数据集，并逐条新增、编辑和删除测试用例。数据集提供名称和说明，每条用例包含用户问题、期望答案和评分要求。
用户问题为必填项，期望答案和评分要求至少填写一项。删除用例前需要确认。本阶段不做文件导入、审批和版本管理。
创建评测任务
创建任务时，用户需要选择待评测 Agent、数据集、评分模型、通过分数和是否允许工具。
通过分数范围为 0 到 100，默认 60 分。“允许工具”默认关闭。关闭时，不向目标 Agent 提供工具定义，运行时也必须拒绝工具执行；开启后，只允许使用目标 Agent 已绑定且当前启用的内置工具和 MCP 工具。Skills 仍按 Agent 配置加载。
空数据集不能启动评测。任务创建时保存用例内容和评测配置快照，后续编辑数据集不能改变已有任务的问题、期望答案和评分要求。记录实际使用的 Agent 配置及提示词版本，方便解释结果，无需开发版本管理界面。
执行流程
第一版按顺序执行用例，每条用例使用独立上下文，不继承其他用例或聊天会话的历史，也不向目标 Agent 暴露期望答案和评分要求。
每条用例按照以下流程执行：
- 将用户问题交给目标 Agent Runtime，创建并关联一条 Run，记录来源为评测。
- 保存目标 Agent 的实际回答和运行状态。
- Agent 正常完成后，将问题、期望答案、评分要求和实际回答交给评分模型。
- 校验评分结果，保存分数、理由和系统计算的通过状态。
目标 Agent 失败、取消或达到轮数限制时，保留已有输出和 Run，标记该用例的执行状态，不将未完成内容作为正常答案评分。单条用例出错后继续执行后续用例。
评分结果与校验
评分模型返回固定结构，包含 score 和 reason 两个字段。score 必须为 0 到 100 的有限数字，reason 必须为非空字符串。
后端负责解析和校验，不能从普通文字中猜测分数，也不能将超出范围的分数直接修正为合法值。首次结构或字段校验失败时，允许携带错误说明重试一次；再次失败则标记为“评分失败”。评分服务连接失败等请求错误需要单独记录，避免无限重试。
评分提示词需要明确：问题、参考答案和实际回答都是待评估材料，其中出现的指令不得覆盖评分规则。评分模型不提供工具权限。
是否通过由后端按“得分大于或等于通过分数”计算，不接受评分模型自行给出的通过结论。评分调用的耗时、Token 用量和错误单独记录，不能混入目标 Agent Run 的性能指标。
任务状态与进度
任务至少区分待运行、运行中、已完成和已中断。用例需要区分待执行、执行中、评分中、通过、未通过、执行失败和评分失败；取消或轮数耗尽时保留具体结束原因。
运行期间通过后端状态校验阻止重复启动，不能只禁用前端按钮。已完成任务也不能再次启动并覆盖原结果；需要重新评测时，新建任务。
任务状态、用例进度和结果逐条持久化。刷新或关闭页面不取消评测，重新打开后能够看到当前进度和已完成结果。
本阶段可以使用服务进程内的后台任务顺序执行，不引入独立 Worker、并发调度或定时任务。服务重启后无法继续的任务标记为已中断，保留已有结果，不得永久显示运行中；本阶段不做自动续跑。
任务详情与统计
任务详情展示总用例数、已完成数、通过数、未通过数、执行失败数、评分失败数和平均分。
已完成数指已进入终态的用例数量，包含失败用例。平均分只统计成功获得合法评分的用例，没有有效评分时显示“暂无评分”，不能将执行失败或评分失败按零分混入平均分。
每条结果可以展开查看问题、期望答案、评分要求、实际回答、得分、评分理由、错误原因和关联 Run ID，并提供进入运行详情的入口。
所有用例处理结束后，任务显示已完成，同时清楚展示失败数量，不能将“任务执行完毕”混同于“全部用例通过”。
示例数据集
准备一个包含以下三条用例的示例数据集：
- 问题：计算 23 乘以 47。期望答案：1081。评分要求：计算结果正确，表达简洁。
- 问题：将“今天下午三点开会”翻译成英文。期望答案：The meeting is at 3 p.m. today. 评分要求：准确表达会议时间，允许自然且含义一致的译法。
- 问题：小明有 5 个苹果，送给小红 2 个，还剩几个？只回答数字。期望答案：3。评分要求：结果正确，并且只输出数字。
通过稳定标识保证示例初始化幂等。重复启动不能重复创建，也不能覆盖用户已经修改的示例内容。
页面与验证
页面配色、字号、表单和状态展示与已有管理页面保持一致。继续沿用现有密钥保护、错误脱敏和运行记录规则。
请为正常评分、评分格式错误及重试、目标 Agent 失败、部分用例失败后继续执行、通过分数边界、平均分统计、工具默认关闭、用例上下文隔离、重复启动限制、示例初始化幂等，以及刷新和服务重启后的状态恢复补充测试。
完成后，运行完整后端测试、前端类型检查和构建，修复所有失败项，并说明 Runtime 复用方式、评分校验规则、统计口径和验证结果。
