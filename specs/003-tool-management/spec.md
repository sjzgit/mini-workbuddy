**Feature Branch**: `003-tool-management`

**Created**: 2026-09-10

**Status**: Draft

**Input**: User description: "按照文档开发工具管理"，详细需求见 `0user chat/3工具管理.md`（用户维护，禁止修改）

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 工具列表与详情 (Priority: P1)

使用者进入"工具管理"页面后，看到系统内置工具组成的列表，每行展示：工具名称、用途说明、参数说明、启用状态，以及是否为系统内置工具。点击某个工具可进入详情页，查看该工具各参数的完整含义（适用场景、输入要求、使用限制），帮助理解模型何时会调用该工具、参数如何填写。当系统中还没有任何工具时，页面展示空状态，而不是空白表格或报错。

**Why this priority**: 列表与详情是工具管理的入口视图，也是使用者理解三类内置工具能力边界的唯一途径；后续所有启停操作和 Agent 调用都以这里的工具信息为准。

**Independent Test**: 打开工具管理页面，核对三类内置工具（当前时间、Shell、文件读写）各自展示名称、用途说明、参数说明、启用状态与内置标记；逐一进入详情页核对参数说明完整可读；清空工具数据后刷新，验证出现空状态。

**Acceptance Scenarios**:

1. **Given** 系统已内置当前时间、Shell、文件读写三类工具， **When** 使用者打开工具管理页面， **Then** 列表完整展示每个工具的名称、用途说明、参数说明、启用状态和是否为系统内置。
2. **Given** 使用者点击某个工具， **When** 进入详情页， **Then** 能看到该工具各参数的完整含义，包括适用场景、输入要求和使用限制。
3. **Given** 系统中没有任何工具数据， **When** 使用者打开工具管理页面， **Then** 页面展示空状态，不出现报错或残缺表格。

---

### User Story 2 - 工具启停 (Priority: P1)

使用者可以在列表页对任意工具（含系统内置工具）执行启用或停用操作，操作需确认后生效，列表中的启用状态即时更新。停用后的工具对后续 Agent 不可见、不可调用；重新启用后恢复可用。系统内置工具允许启停，但界面不提供删除或修改其用途的入口。

**Why this priority**: 启停是使用者控制 Agent 能力边界的核心手段（例如临时禁用 Shell 工具防止误执行命令），直接影响后续 Agent Loop 的调用集合，必须与执行入口同批交付。

**Independent Test**: 停用 Shell 工具后核对列表状态为"已停用"，经统一执行入口调用该工具被拒绝；重新启用后再次调用成功；全程确认内置工具无删除/修改入口。

**Acceptance Scenarios**:

1. **Given** 某工具处于启用状态， **When** 使用者执行停用并确认， **Then** 列表中该工具状态更新为停用，后续经统一执行入口的调用被拒绝并返回明确提示。
2. **Given** 某系统内置工具处于停用状态， **When** 使用者执行启用并确认， **Then** 该工具恢复可用，经统一执行入口可正常调用。
3. **Given** 使用者浏览系统内置工具的操作入口， **Then** 只能启用/停用，不出现删除或修改用途的入口。

---

### User Story 3 - 统一工具执行入口 (Priority: P1)

后续 Agent Loop 调用任何本地工具都经过统一的执行入口。执行前该入口检查：工具是否存在、是否已启用、输入参数是否正确。检查通过后执行工具，执行后返回统一且容易理解的结果；执行失败时返回清楚的错误信息（工具不存在、工具已停用、参数错误、执行出错等），且任何失败都不会让整个后端进程崩溃。

**Why this priority**: 统一执行入口是本阶段的核心交付，也是后续 Agent Loop 的基础设施；启停状态（User Story 2）只有通过它才真正生效，危险操作限制也必须在执行层落实。

**Independent Test**: 分别以"存在的工具 + 正确参数""存在的工具 + 错误参数""不存在的工具""已停用的工具""执行中出错的工具"五种情况调用统一入口，核对五种返回均结构统一、信息可理解，且后端进程全程存活。

**Acceptance Scenarios**:

1. **Given** 一个存在且启用的工具和一组正确输入， **When** 通过统一执行入口调用， **Then** 执行成功并返回统一格式的结果（含执行状态与输出内容）。
2. **Given** 一个不存在的工具名， **When** 通过统一执行入口调用， **Then** 返回"工具不存在"的错误信息，后端进程不崩溃。
3. **Given** 一个存在但已停用的工具， **When** 通过统一执行入口调用， **Then** 返回"工具已停用"的错误信息，后端进程不崩溃。
4. **Given** 输入参数不符合工具的参数要求（缺失、类型错误等）， **When** 通过统一执行入口调用， **Then** 返回指明参数问题的错误信息，后端进程不崩溃。
5. **Given** 工具执行过程中自身出错， **When** 通过统一执行入口调用， **Then** 返回保留清楚的错误信息的结果，后端进程不崩溃。

---

### User Story 4 - Shell 工具与危险命令拦截 (Priority: P1)

使用者（及后续的 Agent）可通过 Shell 工具执行命令（如查看系统信息、搜索文件、运行脚本、执行测试），并获得命令输出与执行状态。工具在执行层拦截危险命令：递归删除根目录或系统目录、格式化磁盘、修改关键系统权限、关闭安全防护、读取并外传密钥、未经检查直接执行远程下载的脚本，均被拒绝执行并返回可理解的拒绝原因。拦截在工具执行层落实，不依靠工具说明约束模型。

**Why this priority**: Shell 工具是能力最强也最危险的内置工具，危险操作限制必须在执行层真实生效——这是用户明确的安全底线，与统一执行入口同优先级交付；它与页面、启停、入口共同构成安全可用的最小交付集。

**Independent Test**: 通过统一入口执行普通命令（如查看系统信息、搜索文件）核对输出与状态；逐一构造各类危险命令（递归删除、格式化、修改关键权限、关闭安全防护、读取外传密钥、直接执行远程下载脚本），核对全部被拦截并返回明确原因，系统未被破坏。

**Acceptance Scenarios**:

1. **Given** 一条普通命令（如搜索文件、执行测试）， **When** 通过 Shell 工具执行， **Then** 返回命令输出与执行状态（成功/失败及输出内容）。
2. **Given** 一条递归删除根目录或系统目录的命令， **When** 尝试执行， **Then** 执行被拦截，返回可理解的拒绝原因，系统文件未被删除。
3. **Given** 一条格式化磁盘或修改关键系统权限的命令， **When** 尝试执行， **Then** 执行被拦截并返回拒绝原因。
4. **Given** 一条关闭安全防护的命令， **When** 尝试执行， **Then** 执行被拦截并返回拒绝原因。
5. **Given** 一条读取并外传密钥的命令， **When** 尝试执行， **Then** 执行被拦截并返回拒绝原因，无敏感信息外传。
6. **Given** 一条未经检查直接执行远程下载脚本的命令， **When** 尝试执行， **Then** 执行被拦截并返回拒绝原因。
7. **Given** 危险命令被拦截的场景， **Then** 拦截发生在实际执行之前，拦截结果以统一执行入口的标准格式返回。

---

### User Story 5 - 当前时间工具 (Priority: P2)

使用者（及后续的 Agent）可通过当前时间工具查询指定时区的当前日期和时间。时区参数使用 IANA 时区名称（如 Asia/Shanghai、America/New_York、Etc/UTC）；使用者未指定时区时，使用系统配置的默认时区。工具说明明确提示避免使用 CST 等含义不明确的缩写。

**Why this priority**: 三类内置工具之一，风险最低、逻辑最简单，是验证统一执行入口与工具信息展示链路的基础用例；相对其他故事属于独立可验证的补充能力。

**Independent Test**: 分别以 Asia/Shanghai、America/New_York、Etc/UTC 查询，核对返回的日期时间与时区正确对应；不传时区参数时返回默认时区的时间；传入 CST 这类模糊缩写时收到指明应使用 IANA 名称的错误提示。

**Acceptance Scenarios**:

1. **Given** 指定时区 Asia/Shanghai， **When** 调用当前时间工具， **Then** 返回北京时间的当前日期和时间，并标明所用时区。
2. **Given** 未指定时区， **When** 调用当前时间工具， **Then** 返回系统配置默认时区的当前日期和时间。
3. **Given** 传入 CST 等非 IANA 名称的模糊缩写， **When** 调用当前时间工具， **Then** 返回错误提示，说明应使用 IANA 时区名称。

---

### User Story 6 - 文件读写工具 (Priority: P2)

使用者（及后续的 Agent）可通过文件读写工具读取、创建和修改授权目录内的文件。工具参数说明明确：文件路径的填写方式（相对授权目录的路径形态）、读写内容的格式（文本内容），以及文件不存在或已存在时的处理规则（读取时文件不存在报错；创建/写入时同名文件已存在的覆盖策略）。授权目录之外的路径被拒绝并返回明确原因。

**Why this priority**: 三类内置工具之一，与 Shell 工具共同构成 Agent 的本地操作能力，授权目录限制是其安全边界；在 P1 交付（页面、启停、入口、Shell 拦截）构成安全可用的最小集合后补齐，完成第一版工具全集。

**Independent Test**: 在授权目录内分别执行读取已有文件、创建新文件、修改已有文件，核对内容正确；对授权目录外的路径发起读写，核对被拒绝并返回原因；读取不存在的文件，核对收到明确报错。

**Acceptance Scenarios**:

1. **Given** 授权目录内存在某文本文件， **When** 通过文件读写工具读取， **Then** 返回该文件内容。
2. **Given** 授权目录内不存在某文件， **When** 尝试读取， **Then** 返回文件不存在的错误信息。
3. **Given** 授权目录内的一个新路径， **When** 通过工具创建文件并写入内容， **Then** 文件创建成功，内容与写入一致。
4. **Given** 授权目录内已存在同名文件， **When** 通过工具写入新内容， **Then** 按参数说明声明的覆盖规则处理，结果可预期。
5. **Given** 授权目录之外的任意路径， **When** 尝试读取或写入， **Then** 操作被拒绝并返回"超出授权目录"的错误信息。

---

### Edge Cases

- 工具数据被清空（如首次部署前）时打开工具管理页怎么办？—— 展示空状态，页面不报错。
- 调用一个不存在或已停用的工具怎么办？—— 统一执行入口返回明确错误信息，不执行任何实际操作，后端不崩溃。
- 时区参数传入 CST 等模糊缩写怎么办？—— 返回错误提示，引导使用 IANA 时区名称。
- 时区参数传入格式合法但不存在（拼写错误）的 IANA 名称怎么办？—— 返回无法识别该时区的错误信息。
- Shell 命令执行超时或长时间无响应怎么办？—— 有执行超时上限，超时返回可理解的失败结果，不无限等待。
- Shell 命令执行失败（非零退出码）怎么办？—— 属于正常执行结果，返回失败状态与输出内容，不算系统错误。
- Shell 工具返回大量输出怎么办？—— 输出有上限截断并明确提示已截断，避免结果无法返回。
- 危险命令以拼接、变量等间接形式构造怎么办？—— 执行层拦截机制尽力识别已知危险模式；无法完全覆盖的极端变形如实返回执行结果，安全兜底依赖授权目录与超时等横向限制。
- 写入的文件路径包含 `..` 等路径穿越片段怎么办？—— 解析后仍落在授权目录内才允许，否则拒绝。
- 写入内容为空或读取空文件怎么办？—— 按正常空内容处理，不报错。
- 同一工具被快速连续调用怎么办？—— 每次调用独立执行、独立返回结果，互不干扰。
- 后端重启后工具启用状态怎么办？—— 启停状态持久化，重启后保持。

## Requirements *(mandatory)*

### Functional Requirements

**工具列表与详情**

- **FR-001**: 系统 MUST 提供"工具管理"页面，以列表展示所有工具，每行包含工具名称、用途说明、参数说明、启用状态和是否为系统内置工具。
- **FR-002**: 系统中不存在任何工具时，页面 MUST 展示空状态，不出现报错或残缺表格。
- **FR-003**: 点击工具 MUST 可进入详情视图（实现以页面内右侧抽屉承载，见 plan/research R8），查看该工具各参数的完整含义（适用场景、输入要求、使用限制）。
- **FR-004**: 工具说明 MUST 明确适用场景、输入要求和使用限制，帮助模型判断何时调用、如何填写参数。

**工具启停与内置保护**

- **FR-005**: 使用者 MUST 能对任意工具（含系统内置工具）执行启用或停用，操作确认后生效，列表状态即时更新。
- **FR-006**: 停用的工具对后续 Agent MUST 不可见、不可调用；重新启用后恢复可用。
- **FR-007**: 系统内置工具 MUST 允许启停，但 MUST NOT 提供删除或修改其用途的入口。
- **FR-008**: 工具及其启用状态 MUST 持久化，刷新页面或重启服务后仍然保留。

**统一执行入口**

- **FR-009**: 系统 MUST 提供统一的工具执行入口，后续 Agent Loop 调用任何本地工具都 MUST 经过该入口。
- **FR-010**: 执行前入口 MUST 检查工具是否存在、是否已启用、输入参数是否正确，任一检查不通过即拒绝执行。
- **FR-011**: 执行后入口 MUST 返回统一且容易理解的结果（执行状态与输出内容）；执行失败时 MUST 保留清楚的错误信息。
- **FR-012**: 任何工具执行失败（工具不存在、已停用、参数错误、执行出错）MUST NOT 导致整个后端进程崩溃。

**内置工具：当前时间**

- **FR-013**: 当前时间工具 MUST 根据指定的 IANA 时区名称（如 Asia/Shanghai、America/New_York、Etc/UTC）返回当前日期和时间；未指定时区时 MUST 使用系统配置的默认时区。
- **FR-014**: 当前时间工具的说明 MUST 提示避免使用 CST 等含义不明确的缩写；传入无法识别的时区时 MUST 返回明确的错误提示。

**内置工具：Shell**

- **FR-015**: Shell 工具 MUST 能执行命令（如查看系统信息、搜索文件、运行脚本、执行测试）并返回命令输出及执行状态。
- **FR-016**: Shell 工具 MUST 在执行层拦截危险命令：递归删除根目录或系统目录、格式化磁盘、修改关键系统权限、关闭安全防护、读取并外传密钥、未经检查直接执行远程下载的脚本；拦截时 MUST 返回可理解的拒绝原因，且拦截 MUST NOT 依赖工具说明对模型的约束。
- **FR-017**: Shell 命令执行 MUST 有超时上限，超时返回可理解的失败结果；输出超过上限时 MUST 截断并明确提示已截断。

**内置工具：文件读写**

- **FR-018**: 文件读写工具 MUST 支持读取、创建和修改授权目录内的文件。
- **FR-019**: 文件读写工具的参数说明 MUST 明确文件路径的填写方式、读写内容的格式，以及文件不存在或已存在时的处理规则。
- **FR-020**: 文件读写工具 MUST 将操作限制在授权目录内：授权目录之外的路径（含通过 `..` 等路径穿越到达的路径）MUST 被拒绝并返回明确原因。

**页面一致性**

- **FR-021**: 工具管理页面的配色、字号、布局和交互方式 MUST 与已有管理页面保持一致。

### Key Entities

- **工具（Tool）**: 一项可供 Agent 调用的本地能力。属性：工具名称、用途说明、参数说明（含各参数的名称、含义、是否必填、格式要求）、适用场景、输入要求、使用限制、是否系统内置、启用状态、创建时间、最后更新时间。系统内置工具允许启停，不允许删除或修改用途。
- **工具执行结果（Tool Execution Result）**: 统一执行入口的标准化返回。属性：执行状态（成功/失败）、输出内容（工具输出、命令输出或文件内容）、失败时的错误信息（工具不存在、已停用、参数错误、执行出错、危险操作被拦截、超出授权目录等）、必要的附加信息（如所用时区、是否截断）。
- **授权目录（Authorized Directory）**: 文件读写工具允许访问的目录范围主定义，授权目录之外的读写一律拒绝。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 使用者打开工具管理页面后，无需查阅外部文档即可理解每个内置工具的用途与参数含义；详情页信息完整的工具占比 100%。
- **SC-002**: 在覆盖"工具不存在、已停用、参数错误、执行出错、调用成功"五类场景的统一入口测试中，100% 返回结构一致的结果格式，且全程后端进程零崩溃。
- **SC-003**: 在针对递归删除、格式化磁盘、修改关键权限、关闭安全防护、读取外传密钥、直接执行远程下载脚本六类危险命令的测试中，拦截率 100%，且每次均返回可理解的拒绝原因，系统未被破坏。
- **SC-004**: 授权目录外的读写尝试 100% 被拒绝并返回明确原因；授权目录内的读写操作 100% 与预期内容一致。
- **SC-005**: 时区查询以 Asia/Shanghai、America/New_York、Etc/UTC 验证，返回时间与时区 100% 对应正确；不传时区时 100% 返回默认时区时间。
- **SC-006**: 任意工具的启停操作后，经统一执行入口验证的可用性变化 100% 即时生效；刷新页面并重启服务后，启停状态 100% 保留。

## Assumptions

- 授权目录的具体位置（如项目内的工作区目录）与默认时区的具体值由 Plan 阶段的系统配置设计确定；默认时区可在系统配置中调整，未指定时的行为以配置为准。
- 危险命令拦截采用"已知危险模式"的执行层校验（命令解析 + 模式匹配），目标是拦截需求列出的六类命令及其常见变体，不承诺拦截所有理论上可构造的恶意命令；横向兜底还包括授权目录限制与执行超时。
- Shell 命令执行超时上限与输出截断上限的具体数值由 Plan 阶段确定，需在工具说明中对使用者/模型明示。
- 文件读写工具本阶段只处理文本内容，二进制文件读写不在范围内。
- "创建文件时同名文件已存在"采用明确的覆盖策略（写入即覆盖），并在参数说明中写明；不提供单独的删除文件能力。
- 统一执行入口的调用方为后续阶段的 Agent Loop；本阶段通过接口测试与页面操作验证其行为，Agent Loop 本身属于后续阶段。
- 工具说明文本（面向模型的适用场景、输入要求、使用限制）随系统内置工具由系统提供，本阶段不提供自定义工具与自定义说明的编辑能力。
- 本产品为单机本地部署、单用户使用，不处理多用户权限与并发冲突。
