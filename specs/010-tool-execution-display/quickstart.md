# Quickstart: 工具执行过程展示（010）验证指南

> 本指南验证 010 阶段端到端行为。契约细节见 [contracts/display-events.md](contracts/display-events.md)，实体见 [data-model.md](data-model.md)。

## 前置条件

1. 后端依赖已安装：`backend/` 内 `uv sync`；数据库已迁移：`uv run alembic upgrade head`
2. 存在可用模型（中转站配置）、至少一个内置工具（如"当前时间"）和一个绑定该工具的 Agent
3. 启动服务：
   - 后端：`backend/` 内 `uv run python start_dev.py`（端口 8218）
   - 前端：`frontend/` 内 `npm run dev`（/api 代理到后端）

## 自动化检查（交付门禁）

```bash
# 后端（backend/ 内）
uv run pytest          # 全部通过（含 010 新增事件字段断言）
uv run pyright         # 无错误

# 前端（frontend/ 内）
npm run build          # 零错误（含 type-check）
npm run test:unit      # 全部通过（store 槽位/终态映射/卡片渲染）
```

## 手动验证场景

### 场景 1: 卡片生命周期（US1）

1. 向绑定了"当前时间"工具的 Agent 发送"现在几点了"
2. **期望**：回复区内正文下方出现卡片"当前时间 · 正在执行"（loading 图标）；数秒内变为"成功 · {耗时}"；卡片默认收起，摘要行显示参数/结果摘要

### 场景 2: 顺序交错（US2）

1. 向 Agent 提出需要"先说明思路 → 调工具 → 再总结"的问题（如"查一下当前时间，然后告诉我今天星期几"）
2. **期望**：工具前的文字在卡片上方，工具后的文字在卡片下方；多次调用出现多张独立卡片，按开始顺序排列

### 场景 3: 展开详情与内容整理（US3）

1. 展开一张成功卡片
2. **期望**：`输入参数` 显示格式化缩进的 JSON；`执行结果` 纯文本展示；均无 HTML 执行痕迹
3. 让 Agent 调用"文件读写"读取一个超过 16000 字符的文件
4. **期望**：结果分区显示前 16000 字符 + `…[已截断，完整内容共 N 字符]` 标注；前端超过 20000 字符再提示"未展示全部"
5. 构造一个必失败的调用（如让 Shell 执行不存在的命令）
6. **期望**：卡片"失败 · {耗时}"，展开显示人话原因；页面任何位置无 `Traceback` 堆栈

### 场景 4: MCP 工具命名（US1/FR-003）

1. 启用一个 MCP Server 并绑定其工具，触发调用
2. **期望**：卡片标题为"Server名 · 工具名"；展开详情内可见内部暴露名（次要文字）

### 场景 5: 滚动与回到最新（US4）

1. 触发一次长回复 + 多工具调用，生成期间向上滚动
2. **期望**：视图不强行拉回底部，右下角出现"回到最新消息"按钮；点击后到达底部并恢复跟随
3. 展开一张卡片（处于上滚状态）
4. **期望**：当前阅读内容不跳动

### 场景 6: 取消与状态未知（US5）

1. 工具执行期间点击"停止生成"
2. **期望**：未完成卡片显示"已取消"（⏹ 图标 + 文字），不停留"正在执行"，不误标成功
3. 工具执行期间直接断开网络（开发者工具 offline）
4. **期望**：流中断，进行中卡片显示"状态未知"（？图标 + 警示色）

### 场景 7: 切换会话续播与历史还原（US6 / Clarify Q2/Q3）

1. 会话 A 生成期间切换到会话 B 再切回
2. **期望**：运行未被取消，卡片与正文从离开时的状态无缝继续更新
3. 切换浏览其他历史会话
4. **期望**：历史消息只显示已保存正文，无卡片、无占位错误
5. 刷新页面后回到原会话
6. **期望**：卡片消失（属预期，运行记录留待后续阶段），正文正常展示，页面无报错
