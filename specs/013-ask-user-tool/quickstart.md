# Quickstart: Ask User 询问工具（第十三阶段）端到端验证

**Date**: 2026-09-18 | **Spec**: [spec.md](spec.md) | **契约**: [contracts/ask-user-api.md](contracts/ask-user-api.md)

## 前置条件

- Node 22（Windows + nvm 见 AGENTS.md §5）与 uv 已安装
- 一个可用的 OpenAI 兼容模型（工具调用能力），已登记并设默认
- 一个 Agent，绑定"询问用户"工具

## 启动

```bash
# 后端（backend/ 内）
uv sync
uv run alembic upgrade head        # 播种 ask_user 工具行
uv run uvicorn app.main:app --reload --port 8218

# 前端（frontend/ 内，新终端）
npm run dev
```

## 验证场景

### 场景 1：治理（US1 / FR-001~003）

工具管理页出现"询问用户"内置工具，详情含三节说明与参数表；可启停。给测试 Agent 绑定该工具；另建一个未绑定的 Agent 作对照。

### 场景 2：开放式问答端到端（US2 / FR-004/005/009/010）

向绑定 Agent 发送："帮我写一段自我介绍，但先问我想用在什么场合再写。"

1. 模型调用询问用户 → 聊天界面弹窗展示问题与输入框（tool 卡片同时出现）。
2. 不回答前无新输出（运行暂停）。
3. 输入"求职面试"提交 → 弹窗关、卡片显示回答、模型继续生成自我介绍且面向面试场合。
4. 运行记录（运行记录页）能看到该工具调用的问题与回答。

### 场景 3：选项式（US3 / FR-006~008）

发送："问我要生成周报还是日报，给出选项让我选，并支持我手动输入别的。"（或使用系统提示引导模型用选项式）

1. 弹窗展示选项 + 末尾自动出现"其他，我手动输入"。
2. 单选时只能选一项；让模型指定多选时可勾选多项。
3. 选中"其他"→ 下方出现输入框；输入自定义内容提交 → 模型回复体现自定义内容。
4. 什么都不选/输入空格点提交 → 被阻止（按钮不可用或提示）。

### 场景 4：取消与恢复（US4 / FR-011/012）

1. 弹窗等待中点"停止" → 运行取消终态、弹窗关闭、立即能发新消息。
2. 再发起询问，回答前刷新页面 → 弹窗重新出现（问题/选项不变）→ 正常回答 → 运行继续。

### 场景 5：超时与无人值守（US5 / FR-013/014）

1. `uv run python -c` 临时把 `ask_user_timeout_seconds` 调小（或环境变量重启）→ 发起询问不回答 → 到时运行收尾（模型收到"未在时限内回答"），会话可继续。
2. 评测页创建含该 Agent 的任务运行 → Case 中模型调用该工具 → 立即收到"没有用户可以回答"失败结果，评测不挂起、正常出分。
